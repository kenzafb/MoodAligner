# MoodAligner

Application web qui recommande des contenus (musique, textes, images, vidéos) en fonction de l'état émotionnel indiqué par l'utilisateur.

Projet réalisé dans le cadre de la SAÉ du semestre 3, BUT Informatique, IUT de Villetaneuse (2026). Client : Gaël Guibon.
